# FieldOps Hub

FieldOps Hub is a portfolio-grade multi-tenant field service operations platform for managing customers, work orders, technician assignments, attachments, approvals and audit records.

> Current status: Phase 1 — repository and application foundation.

## Planned stack

- React and TypeScript
- ASP.NET Core on .NET 10 LTS
- PostgreSQL and Entity Framework Core
- Docker Compose
- GitHub Actions

## Project objective

The project demonstrates enterprise product engineering through tenant isolation, role-based workflows, state transitions, concurrency handling, automated tests, observability and reproducible deployment.
