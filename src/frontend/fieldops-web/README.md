# FieldOps Web Application

React and TypeScript client for FieldOps Hub.

## Commands

```bash
npm ci
npm run dev
npm run lint
npm run test:run
npm run build
```

## Responsibilities

- JWT session handling
- Protected role-aware routes
- Customer and work-order management
- Dispatcher and technician workflow
- Client review
- Work-order attachments
- Audit history
- Operational reporting

API requests use the configured Vite or Nginx reverse proxy.
