# FieldOps Hub v0.2.0 — Multi-Tenant Data Foundation

## Added

- Tenant, Customer and persistent WorkOrder entities
- PostgreSQL and Entity Framework Core persistence
- Initial versioned database migration
- Fictional two-tenant demonstration data
- Tenant-aware query filters
- Tenant-scoped uniqueness and relationship constraints
- Six PostgreSQL isolation and negative integration tests
- Dedicated PostgreSQL GitHub Actions job
- Final 15-image repository policy

## Security and reliability

- Remediated the vulnerable Microsoft.OpenApi transitive dependency
- Verified direct and transitive NuGet dependencies
- Missing tenant context returns no business rows
- Cross-tenant WorkOrder/Customer relationships are rejected
- Temporary integration-test databases are created and removed automatically

## Known limitations

Authentication, role authorisation, complete REST endpoints, file attachments, audit persistence, reporting and cloud deployment are not included in this release.
