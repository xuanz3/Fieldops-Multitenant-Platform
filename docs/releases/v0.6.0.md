# FieldOps Hub v0.6.0 — Role-Owned Operational Workflow

## Added

- Customer-to-Client ownership
- WorkOrder-to-Technician assignment
- Dispatcher assignment and ownership workspace
- Technician task queue
- Technician start and completion submission actions
- Client work queue
- Client approve and reopen actions
- Completion summaries and reopen reasons
- Assignment and workflow timestamps
- Role-aware navigation and dashboard
- Composite Tenant relationship constraints
- Workflow unit, HTTP integration and frontend tests
- Full browser workflow smoke validation

## Security behaviour

Technicians can act only on their assigned WorkOrders. Clients can view and decide only WorkOrders belonging to linked Customers. Every workflow write uses optimistic concurrency, and all relationships remain Tenant-scoped.

## Known limitations

Attachments, immutable audit events, reporting, notifications, secure production cookie authentication and cloud deployment remain future work.
