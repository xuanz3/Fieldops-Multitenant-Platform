# FieldOps Hub v0.7.0 — Evidence, Audit and Reporting

## Added

- controlled WorkOrder attachments
- PDF, PNG, JPEG and TXT allow-list
- 5 MB file limit
- SHA-256 attachment integrity metadata
- authorised attachment download
- automatic tenant audit events
- per-Tenant SHA-256 audit chain
- audit-chain verification API
- PostgreSQL append-only audit trigger
- searchable audit log page
- operations reporting API
- Technician and Customer workload tables
- CSV report export
- Evidence and Reports pages
- fictional demo evidence
- Phase 7 unit, PostgreSQL/API and frontend tests

## Updated

- React Router migrated to react-router 8.3.0
- README updated for the Phase 7 product
- local demo seed now includes attachment and audit evidence

## Known limitations

The local demonstration stores small files in PostgreSQL. Production object storage, malware scanning, external audit anchoring, notifications and cloud deployment remain later concerns.
