# FieldOps Hub v0.4.0 — Tenant-Safe Business APIs

## Added

- Customer list, search, pagination, detail, create and update endpoints
- WorkOrder list, filter, pagination, detail, create and update endpoints
- String enum API serialization
- WorkOrder optimistic concurrency through Version
- Duplicate reference conflict responses
- Cross-tenant identifier protection
- Business API integration tests

## Security behaviour

Business data remains scoped by the validated signed tenant claim. Caller-supplied tenant headers are ignored. Tenant Admin and Dispatcher roles manage Customer and WorkOrder records; other roles receive 403.

## Known limitations

Technician assignment, Client ownership, workflow transition endpoints, attachments, audit persistence, reporting and the production frontend remain future work.
