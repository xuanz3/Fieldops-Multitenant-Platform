# FieldOps Hub v0.5.0 — Frontend Business Workspace

## Added

- Authenticated React business workspace
- JWT sign-in and session management
- Dashboard metrics
- Customer search, create and update UI
- WorkOrder search, filters, create and update UI
- Version-conflict feedback
- Responsive application shell
- Typed API client
- Frontend unit and component tests
- One-command local demonstration launcher
- Browser-to-real-API smoke test

## Security behaviour

The browser does not choose a Tenant ID. Business requests use the signed JWT tenant claim. The local Vite proxy preserves a same-origin `/api` path. Sessions are stored only for the current browser tab.

## Known limitations

Technician assignment, Client ownership, workflow transitions, attachments, audit persistence, reporting, secure production cookie authentication and cloud deployment remain future work.
