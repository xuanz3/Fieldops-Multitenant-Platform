# FieldOps Hub v0.3.0 — Tenant-Aware Identity

## Added

- Tenant-scoped user accounts
- PBKDF2-SHA256 password hashing
- JWT login and authenticated identity endpoints
- Signed tenant claim resolution
- Tenant Admin, Dispatcher, Technician and Client roles
- Role-based endpoint policies
- Authenticated tenant summary
- Fictional demo users
- HTTP API security tests

## Security behaviour

Invalid credentials and malformed tokens return 401. Incorrect roles return 403. Tenant context is read from a validated signed claim, and caller-supplied tenant headers are ignored. The signing key is supplied through configuration.

## Known limitations

Refresh tokens, revocation, MFA, account lockout, password reset and external identity providers remain future work.
